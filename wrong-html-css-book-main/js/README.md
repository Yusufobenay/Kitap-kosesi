# ODAK Audio - JavaScript Entegrasyon Planı

Bu dizin, ODAK Audio e-ticaret platformunun dinamik işlevlerini barındırır. HTML ve CSS (UI/UX) yapılandırmaları başarıyla tamamlanmış olup, geliştirilecek temel JavaScript modülleri aşağıda projelendirilmiştir:

* **Arama ve Filtreleme (`search.js`):** Dinamik ürün arama, kulaklık/hoparlör kategori filtreleri ve fiyat sıralaması.
* **Sepet İşlemleri:** Ürün ekleme/çıkarma, sepet rozeti güncelleme, ara toplam ve kargo hesaplamaları.
* **Etkileşimli UI:** Arama modalları, açılır menüler (dropdown) ve mobil uyumlu menü animasyonları.
* **Asistan Entegrasyonu (`chatbot.js`):** Kullanıcılara ürün seçiminde yardımcı olacak etkileşimli sohbet botu.
